# Fruitfall (Switch remake)
Rules: rotate the board, fruit falls toward the bottom, 3+ touching fruit of one kind vanish, chains score more. Clear all fruit.
Controls: L/R (or D-pad left/right) rotate, X restart, Y skip, B back, Minus quit.
Build: push to GitHub, run the "Build Switch NRO" action, download fruitfall.nro, put in /switch/.
